## 🧑‍💻 What I'm building

**[homelab](https://github.com/albinkarlsson1999/homelab)**
My self-hosted Raspberry Pi server, managed with GitOps: every service is a Docker Compose file in Git, deployed automatically through Portainer. VLAN-segmented UniFi network, Traefik with wildcard TLS, Cloudflare Tunnel for remote access, and secrets kept out of Git.

**[CO-Calendar](https://github.com/albinkarlsson1999/co-calendar)**
An open-source shared calendar and list app (Node.js, Express, MariaDB). Signed-cookie auth, XSS-safe rendering, sharing between users and a promise-based dialog system. Built together with a classmate.

**[portfolio](https://albinkarlsson.dev)**
My personal website, built with React and Vite. Bilingual (Swedish/English), data-driven project cards, an accessible image lightbox and automatic deployment to GitHub Pages with GitHub Actions.

## 🏠 Homelab & IoT
I run a small self-hosted setup at home on two Raspberry Pis — one as a home server and one running LibreELEC/Kodi as a media center streaming from Jellyfin.
- **UniFi Cloud Gateway Ultra** with VLAN segmentation, keeping IoT devices isolated from the main network
- **Home Assistant**, **PostgreSQL**, **Pi-hole**, **Jellyfin**, **Homepage** and **Portainer** — all in Docker
- **Traefik** as reverse proxy with a Let's Encrypt wildcard certificate
- Secure remote access through **Cloudflare Tunnel** and **WireGuard**
- A heavily modified **Ender 5 Pro** running **Klipper**, monitored from Home Assistant via **Moonraker**
