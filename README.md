## Hi there, I'm Albin 👋

Software development student at Jönköping Technical University (graduating 2028)
Before tech I worked as a cook and trained as an electrician so I am used to fast-paced work and love it when software meets real hardware

## 🧑‍💻 What I'm building

**[CO-Calendar](http://github.com/alexanderSaila/Web-Development-Project)**
An open-source shared calendar and list app (Node.js, Express, MariaDB). Signed cookie auth, XSS safe rendering, sharing between users and promise-based dialog systems. Built together with a classmate

## 🏠 Homelab & IoT
I run a small self-hosted setup at home on 2 Raspberry Pis:
- **UniFi Cloud Gateway** with VLAN segmentation, keeping IoT devices isolated from the main network
- **Home assistant**, **PostGreSQL**, **Jellyfin**, **Portainer** - all in Docker
- Secure remote access through **Cloudflare tunnel**
- A heavily modified **Ender 5 Pro** running **Klipper** monitored from Home Assitant via **Moonraker**

## On the workbench
ESP32 based temperature/humidity and soil-moisture sensors, a smart shelf-lamp and WLED controlled LED lighting - All wired into Home Assistant

I care about owning my own data, so I prefer open-source and self-hosting where I can
