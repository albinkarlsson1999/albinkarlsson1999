## 🧑‍💻 What I'm building

**[homelab](https://github.com/albinkarlsson1999/homelab)**
My self-hosted Raspberry Pi server, managed with GitOps: every service is a Docker Compose file in Git, deployed automatically through Portainer. VLAN-segmented UniFi network, Cloudflare Tunnel for remote access, and secrets kept out of Git.

**[CO-Calendar](https://github.com/alexanderSaila/Web-Development-Project)**
An open-source shared calendar and list app (Node.js, Express, MariaDB). Signed-cookie auth, XSS-safe rendering, sharing between users and a promise-based dialog system. Built together with a classmate.

## 🏠 Homelab & IoT
I run a small self-hosted setup at home on two Raspberry Pis — one as a home server and one running LibreELEC/Kodi as a media center streaming from Jellyfin.
- **UniFi Cloud Gateway** with VLAN segmentation, keeping IoT devices isolated from the main network
- **Home Assistant**, **PostgreSQL**, **Pi-hole**, **Jellyfin**, **Homepage** and **Portainer** — all in Docker
- Secure remote access through **Cloudflare Tunnel** and **WireGuard**
- A heavily modified **Ender 5 Pro** running **Klipper**, monitored from Home Assistant via **Moonraker**

### 🔧 On the workbench
ESP32-based temperature/humidity and soil-moisture sensors, a smart shelf lamp and WLED-controlled LED lighting — all wired into Home Assistant.

I care about owning my own data, so I prefer open source and self-hosting where I can.
